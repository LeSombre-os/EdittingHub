📖 Mettre les marqueurs dans DaVinci Resolve — mode d'emploi

Méthode 1 — la plus simple (recommandée)

  1. Analysez la musique, cochez les rangs voulus.
  2. Cliquez ⚡ Envoyer à DaVinci.
  3. Dans Resolve : Workspace → Scripts → EdittingHub Beat Markers.
  4. Ouvrez la timeline où doit aller la musique, puis relancez le script depuis le menu.

⚠ La toute première installation demande de redémarrer DaVinci Resolve (il ne lit le dossier Scripts qu'au démarrage). Ensuite, plus besoin : le fichier est relu à chaque clic.

Le script se place dans ~/.local/share/DaVinciResolve/Fusion/Scripts/Utility/. Vous pouvez le lancer autant de fois que vous voulez, sur n'importe quelle timeline ouverte.

Méthode 2 — sans redémarrage (console)

  1. Cliquez 🐍 Télécharger le .py et ouvrez le fichier dans un éditeur de texte.
  2. Dans Resolve : Workspace → Console (Alt+Maj+C), onglet Python (surtout pas Lua).
  3. Copiez tout le contenu du fichier, collez-le, puis Ctrl+Entrée.

Le script n'importe rien et n'utilise que l'objet resolve déjà fourni par Resolve : c'est ce qui évite le plantage (SIGSEGV) provoqué par les anciens scripts qui rechargeaient fusionscript.so.

Résultat attendu

Timeline  : Ma timeline
FPS       : 24.0
Marqueurs : 101 / 101
OK - marqueurs ajoutes sur la timeline active.

Les marqueurs apparaissent sur la règle de temps : rouge = rang 1 (impact fort), jaune = rang 2 (intermédiaire), bleu = rang 3 (micro-variations).

Si ça ne marche pas

  • « objet resolve introuvable » → le script a été lancé depuis un terminal externe. Sur Resolve Free Linux, le scripting externe renvoie toujours None : passez par le menu Scripts ou la console.
  • « aucune timeline active » → double-cliquez une timeline dans le Media Pool, puis relancez.
  • L'entrée n'apparaît pas dans Workspace → Scripts → redémarrez Resolve (première installation uniquement).
  • Rien ne s'affiche sur la règle → cliquez sur la timeline pour lui donner le focus, puis relancez.

Et les exports fichier ?

CSV, EDL et FCPXML restent disponibles (archivage, autres logiciels). En revanche, l'import FCPXML/EDL dans Resolve Free sous Linux ne restitue pas les marqueurs : c'est une limite du logiciel, pas de l'export. Pour Resolve, utilisez le script.

Réglages du montage

Chaque plan prend le morceau suivant de la vidéo, dans l'ordre. Les beats trop proches sont fusionnés (durée min), les silences trop longs sont subdivisés (durée max). Si la musique dure plus longtemps que la vidéo, le rush est relu depuis le début (option « Boucler »).
